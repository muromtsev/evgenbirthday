# 🎂 evgenbirthday

Праздничная страница-поздравление с обратным отсчётом до дня рождения.

## 🚀 Live

**[LIVE](https://muromtsev.github.io/evgenbirthday)**

## ✨ Что внутри

- ⏱ Обратный отсчёт до 17 ноября (00:00 МСК)
- 🎉 Поздравление на 24 часа + конфетти-салют
- 🔁 Автоматический переход на следующий год
- 🎵 Фоновая музыка (по кнопке)
- ✨ Мерцающие искры на фоне
- 📱 Адаптивная вёрстка

## 🛠 Стек

Чистый HTML + CSS + JavaScript. Без сборки и зависимостей.

## 📁 Файлы

- `index.html` — разметка
- `style.css` — стили
- `script.js` — логика таймера, конфетти, музыки, искр
- `music.mp3` — фоновый трек (опционально)
